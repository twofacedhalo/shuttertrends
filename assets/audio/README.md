# Camera shutter audio

camera-shutter.wav is an original synthesized two-stage mechanical shutter sound created for this project, using no recorded or third-party samples. It is released under CC0-1.0. This license applies only to this generated sound, not the site's photographs or branding.

Format: 0.27 seconds, mono 44.1kHz, 16-bit PCM WAV (about 24KB). Regenerate with tools/create_shutter_sound.py. The camera interaction plays it at 30% volume, only after logo activation; the browser's media policy and the visitor's mute preference remain authoritative.
